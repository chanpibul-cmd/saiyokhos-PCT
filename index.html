ใส่ URL ที่ได้จากการกด "ทำให้ใช้งานได้เป็นเว็บแอป" (Deploy as Web App) ใน Apps Script
การติดตั้ง Google Apps Script

ทำตามขั้นตอนง่าย ๆ 4 ขั้นตอนเพื่อเชื่อมต่อระบบแบบเต็มรูปแบบ:

  1. เปิด Google Sheet > ไปที่เมนู "ส่วนขยาย" (Extensions) > "Apps Script"
  2. คัดลอกโค้ดจากไฟล์ Code.gs ไปวางทับในหน้าจอ Script Editor
  3. กดปุ่ม "ทำให้ใช้งานได้" (Deploy) > "การทำให้ใช้งานได้รายการใหม่" (New deployment) > เลือกประเภท "เว็บแอป" (Web app)
  4. ตั้งค่า: สิทธิ์เข้าถึงเป็น "ทุกคน" (Anyone) > กด Deploy แล้วคัดลอก Web App URL มาใส่ในช่องด้านซ้าย
